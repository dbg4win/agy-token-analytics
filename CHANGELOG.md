# Changelog

All notable changes to **Token Analytics** will be documented in this file.

## [1.0.0] - 2026-11-25

### Initial Release
- Current context saturation gauge, 4-bucket composition breakdown, compaction detection, and per-turn growth chart.
- Custom persistent alert thresholds (by `%` or absolute tokens) with quick presets.
- Session token analytics, subagent rollup, model breakdown, turn-by-turn table, and one-click Markdown report export.
- Prompt Cache savings & estimated USD/CNY API cost calculator with per-model custom pricing overrides.
- Thinking/answer composition, autonomy leverage metrics, latency distribution, and 5-minute idle-gap focus duration tracking.
- Agent-wide overview with 6 color-coded KPI cards, time/project filters, and 3 sub-tabs (Trends & Rhythm, Projects & Models, searchable/sortable Top Conversations).
- Bilingual Chinese/English UI, Antigravity theme & font synchronization, and zero-dependency Node.js standalone mode.
